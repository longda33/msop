## 1. 设计定位

一句话：**一个安静的私人唱片架，点开就是聆听室。**

这个 App 不卖音乐、不推荐音乐、不社交。用户打开它只有两个目的：**找歌**、**听歌**。所以界面的全部复杂度都该花在这两件事上，其余一律让路。

三条原则，按优先级排序，冲突时上位覆盖下位：

| # | 原则 | 具体含义 | 反例（明确不做） |
|---|---|---|---|
| 1 | **一屏之内可完成** | 播放页不跳走、队列不跳走、歌词不跳走——都在同一层浮层内切换 | 歌词独立页、队列独立页 |
| 2 | **手比眼快** | 高频动作落在拇指区（屏幕下 1/3），且不超过一次点击 | 把「播放全部」放进二级菜单 |
| 3 | **安静的界面** | 无色块噪音、无渐变装饰、无动画炫技；颜色只用来表达状态 | 彩虹标签、彩色来源徽章、开屏动画 |

## 2. 四个决策（06 §8 的 Q1–Q4）

### Q1 · 底部导航 —— **音乐库 / 搜索 / 设置（3 个）**

| 方案 | 判断 |
|---|---|
| **音乐库 / 搜索 / 设置** | ✅ **采用**。三个目的地，拇指横向移动距离最短；「设置」虽低频但自用工具必须常驻 |
| 音乐库 / 最近 / 设置 | ❌ 「最近」是伪需求：真正常用的是「继续上次那首」，那由迷你播放条承担 |
| 音乐库 / 播放列表 / 设置 | ❌ 自建歌单是低频动作，不配占一个常驻位 |

**歌单入口**：音乐库页右上角一个图标（收藏夹），进入歌单列表（独立路由）。不占底部导航。
**搜索为什么独立成 Tab**：本地库 + OpenList 两个源合并检索，是这个 App 的核心差异能力，且大库（5000+ 首）场景下搜索频次高于专辑浏览。

### Q2 · 歌曲列表封面 —— **显示 44dp 封面，并提供「紧凑模式」**

理由：
1. **识别效率**。用户找歌时先认封面再看文字，这是音乐类 App 的通用心智（Apple Music / Spotify / 网易云一致）。
2. **成本已被吃掉**。P1-07 已实现封面落盘（300×300）+ 预热（30 首 400ms），Coil 内存缓存 + LazyColumn 只组合可见项，44dp 解码开销可忽略。
3. **兜底**。无封面时显示「首字母 + 从曲名哈希出的低饱和底色」占位块，不留灰洞。

**紧凑模式**（设置项，默认关）：隐藏封面，行高 64 → 52dp，一屏多显示 4 行。给 1 万首以上的库用。

### Q3 · 播放页形态 —— **全屏 overlay，不入返回栈**

不是 `ModalBottomSheet`，是**自定义全屏浮层 + 封面共享元素放大**。原因：

| 问题 | ModalBottomSheet | 自定义 overlay |
|---|---|---|
| 与「左右滑切歌」手势冲突 | 会抢横向拖拽 | 无冲突 |
| 下滑收起时的阻尼手感 | 受 sheet 内部 scroll 影响 | 完全可控（`AnchoredDraggable`） |
| 返回栈污染 | 需手动处理 | 天然不入栈 |
| 封面放大转场 | 难做 | 共享元素直接做 |

**行为契约**：返回键 = 收起浮层（不是退出 App，也不是回到列表）；浮层收起后回到进入前的位置，滚动位置不丢。

### Q4 · 整体路线 —— **B：保留 Primuse 的视觉语言，组件用 Material 3**

`docs/06` §9 的实测结论不变：核心 5 屏可到 85% 神似，追 95% 要多花 3–4 周且仍会被一眼认出是安卓。
但 B 路线不等于「照抄 iOS」，本方案在 B 之上加了两处**自有主张**（详见 §3.1、§3.2），让它像「同一个设计语言」而不是「一个模仿品」：

1. **双空间**：浏览态与播放态是两套视觉，切换有明确的仪式感。
2. **封面主色驱动**：播放页氛围色从当前封面提取，每首歌换一次「房间灯光」。

## 3. 视觉语言

### 3.1 双空间（本方案的核心结构）

| | **唱片架**（浏览态） | **聆听室**（播放态） |
|---|---|---|
| 页面 | 音乐库 / 专辑 / 艺术家 / 文件夹 / 搜索 / 设置 | 播放页 / 歌词 / 队列 |
| 主题 | 跟随系统（浅色 / 深色）+ 动态取色 | **恒定深色**，不受系统主题影响 |
| 底色 | `surface`（近白 / 近黑） | `#0A0B0E` 基底 + 封面主色 12% 径向渐晕 |
| 密度 | 高（行高 64dp，边距 16dp） | 低（大量留白，封面占宽 78%） |
| 信息 | 文字优先 | 封面优先 |
| 动效 | 快（120–180ms，ease-out） | 慢（280–400ms，spring 低刚度） |

**为什么播放页恒定深色**：不是审美偏好，是三个实际收益——大封面在深底上对比最强；OLED 息屏听歌省电；用户从任何主题进来，播放页都是同一个「房间」，形成肌肉记忆。
**为什么不是模糊封面背景**：Compose 做实时模糊（`RenderEffect`）在 API 31 以下无解，且滚动/切歌时掉帧。**用封面取一个主色做径向渐晕，成本 1 行代码，视觉收益 80%**。

### 3.2 色彩

**浏览区**：全部走 `MaterialTheme.colorScheme`，Android 12+ 动态取色。
无动态取色时回落到本方案的种子色：

| 令牌 | 值 | 用途 |
|---|---|---|
| `seed` | `#2F4B8F` | 种子色（靛蓝，沉稳，与「唱片架」气质一致） |
| `primary` | `#3A5AA8` | 选中态、主要按钮、Tab 指示条 |
| `surface` | `#FBFBFD` / `#111318` | 页面底色 |
| `surfaceContainer` | `#FFFFFF` / `#1A1D23` | 卡片、迷你播放条 |
| `onSurface` | `#14161A` / `#E9EAEE` | 主文字 |
| `onSurfaceVariant` | `#5C6270` / `#A0A6B4` | 副文字 |
| `outlineVariant` | `#E4E6EC` / `#2A2E36` | 分割线（0.5dp，仅列表内） |

**语义色**（全 App 只有这三处用彩色，其余一律中性）：

| 语义 | 浅色 | 深色 | 用在哪 |
|---|---|---|---|
| success | `#2E7D5B` | `#6FD3A6` | 服务器连接成功 |
| warning | `#B26A00` | `#F2B457` | `http://` 明文地址警告 |
| danger | `#B3261E` | `#F2B8B5` | 清理缓存、删除歌单 |

**播放区**（固定值，不随主题）：

| 令牌 | 值 |
|---|---|
| `stage` | `#0A0B0E` |
| `stageTint` | 封面主色 @ 12% 不透明度，`radialGradient` 中心偏上 |
| `onStage` | `#FFFFFF` |
| `onStageSecondary` | `#FFFFFF` @ 66% |
| `onStageTertiary` | `#FFFFFF` @ 40% |
| `stageTrack` | `#FFFFFF` @ 12%（进度条轨道） |
| `stageAccent` | 封面主色提升到 L* 72（保证在深底上可读） |

**来源标识不用颜色**（沿用 06 的结论）：本机用 `smartphone` 小图标，云端用 `cloud` 小图标，12dp，`onSurfaceTertiary` 色，只在**混合列表**里出现；纯本机列表不显示。

### 3.3 字体

系统默认字体（Roboto / Noto Sans SC），**不打包第三方字体**。层级靠字号 + 字重 + 字距建立。

| 令牌 | 字号/行高 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| `displayLarge` | 28 / 34 | 600 | -0.5 | 页面大标题（可折叠） |
| `titleLarge` | 20 / 26 | 600 | -0.2 | 播放页歌名 |
| `titleMedium` | 17 / 22 | 600 | 0 | 列表主标题、专辑名 |
| `bodyMedium` | 14 / 20 | 400 | 0 | 正文、副标题 |
| `labelMedium` | 12 / 16 | 500 | 0.2 | 时长、计数、芯片 |
| `caption` | 11 / 14 | 400 | 0.3 | 辅助说明、格式标签 |
| `lyricIdle` | 15 / 28 | 400 | 0 | 歌词非当前行 |
| `lyricActive` | 20 / 32 | 600 | -0.2 | 歌词当前行 |

**数字用 tabular figures**（`FontFeatureSettings("tnum")`），保证时长右对齐不跳动。

### 3.4 间距、形状、海拔

| 令牌 | 值 |
|---|---|
| 屏幕边距 | 16（横屏大屏 24） |
| 列表项 | 上下 8 / 左右 16（含 44dp 封面后总高 64） |
| 分组间距 | 24 |
| 元素间距 | 8 |
| 紧凑间隙 | 4 |
| 最小触摸目标 | 48 × 48 |

| 形状 | 圆角 |
|---|---|
| 列表小封面 44dp | 6 |
| 网格专辑封面 | 12 |
| 播放页大封面 | 20 |
| 卡片 / 对话框 | 16 |
| 底部面板顶部 | 28 |
| 迷你播放条 | 20（胶囊） |
| 芯片 / 按钮 | 全圆角 |

**海拔**：全 App 不用 `shadow`，用「底色差 + 0.5dp 描边」表达层级。唯一例外：迷你播放条用 8dp 阴影（它必须浮在内容之上）。

### 3.5 图标

Material Symbols Rounded，24dp（列表内 20dp），线宽 400（Rounded 默认）。
**不用填充/描边混排**：导航栏选中用填充，其余一律描边。

### 3.6 封面处理

- 列表/网格：`ContentScale.Crop` + `placeholder`（哈希色块）+ `error`（同 placeholder）。
- 播放页：`Crop` + 20dp 圆角 + **1dp 内描边** `#FFFFFF` @ 8%（在深底上勾出边缘，避免深色封面融入背景）。
- 取色：`androidx.palette` 从同一张 300×300 缓存图取 `VibrantSwatch ?: MutedSwatch ?: DominantSwatch`，结果按曲目 id 缓存在内存 LRU（32 条）。

## 4. 屏幕规格

原型中每屏都有对应画框，编号一致。

### L1 · 音乐库 · 歌曲

```
┌─────────────────────────────┐
│ 音乐库            [歌单][排序]│  ← 大标题 28/600，滚动时折叠为 20 顶栏
│ 歌曲  专辑  艺术家  文件夹    │  ← PrimaryTabRow，4 段，指示条 3dp
│ (全部)(本机)(云端)           │  ← 来源芯片，高 32，仅混合源时显示
├─────────────────────────────┤
│ ▣  晴天            周杰伦 4:29│  ← 44 封面 + 标题 + 副标题 + 时长
│ ▣  七里香          周杰伦 4:59│
│ ...                          │
├─────────────────────────────┤
│ ▣ 晴天  ────────────  ⏸  ⏭ │  ← 胶囊迷你播放条（悬浮 8dp）
├─────────────────────────────┤
│  音乐库      搜索      设置   │  ← NavigationBar 80dp
└─────────────────────────────┘
```

- 列表项：`TrackRow`，高 64dp。左 44dp 封面（圆角 6），中列标题 17/600 + 副标题 14/400（艺术家 · 专辑），右列时长 12/500 + 来源图标。
- **整行可点，点击即播并把当前列表设为队列**（不是只播一首）。
- 长按 → 上下文 `ModalBottomSheet`：下一首播放 / 加入歌单 / 查看文件信息 / 在文件夹中显示。
- 正在播放的行：标题变 `primary` 色，封面右下角叠一个 12dp 的三条跳动音柱（**静态三横线，不做动画**，避免列表内动画开销）。
- 滚动时大标题折叠，Tab 行吸顶（`stickyHeader`）。

### L2 · 音乐库 · 专辑

2 列网格（手机）/ 3–4 列（横屏）。每项：正方形封面（12 圆角）+ 专辑名（17/600，1 行省略）+ 艺术家 · N 首（14/400）。
点卡片 → 专辑详情（独立路由）。**不直接播放**。

### L3 · 音乐库 · 艺术家

列表，行高 72。左 48dp 圆形头像（无图则首字母），中列名称 + 「N 张专辑 · M 首」，右侧箭头。

### L4 · 音乐库 · 文件夹

层级导航，顶部面包屑（`本机 / Music / Rock`，可点任意一级回退）。行高 56：文件夹图标 + 名称 + 子项数。
**本机路径与 OpenList 路径分两组**，组标题「本机」「云端」12/500 大写间距。

### D1 · 专辑详情

可折叠头图：大封面（160dp，居中）+ 专辑名 + 艺术家 + 「N 首 · 总时长」。下方「播放全部」实心按钮 + 「随机播放」描边按钮并排（各 50% 宽，高 48）。
曲目列表用 `TrackRow`，显示 trackNo 而非封面（避免同专辑重复封面）。

### P1 · 播放页 · 封面

```
┌─────────────────────────────┐
│  ⌄            正在播放    ⋮  │  ← 收起箭头 / 来源标签 / 更多
│                             │
│      ┌───────────────┐      │
│      │               │      │  ← 封面 78% 宽，20 圆角，1dp 内描边
│      │    封面       │      │     背景 = stage + 封面主色渐晕
│      └───────────────┘      │
│                             │
│  晴天                       │  ← 20/600，左对齐
│  周杰伦 · 叶惠美             │  ← 14/400 @66%
│                             │
│  ──────●────────────────    │  ← 3dp 轨道，主色已播段
│  1:12                4:29   │  ← 12/500 tabular
│                             │
│    ⤮     ⏮    ▶    ⏭    ⟳  │  ← 随机/上一/播放/下一/循环，播放键 64dp 实心
│                             │
│   歌词      队列     定时   ⤴ │  ← 四个文字入口，12/500
└─────────────────────────────┘
```

- 封面区域支持**左右滑切歌**（边缘各留 24dp 给系统返回手势）。
- 垂直下滑收起，跟手阻尼，松手速度 > 800dp/s 或位移 > 30% 即收起。
- 播放键 64dp 白色实心圆 + 深色图标；其余 44dp 描边图标。
- 无歌词时「歌词」入口置灰（不隐藏，保持布局稳定）。

### P2 · 播放页 · 歌词

同一浮层内的第二种形态，点「歌词」或点封面切换（封面缩小到 56dp 移入顶栏，`animateContentSize` 300ms）。
歌词区：`LazyColumn`，当前行 20/600 白色，非当前 15/400 @40%，行间距 28。
- 点击任意行 → seek 到该行时间。
- 手动滑动后 5s 无操作自动回中（`animateScrollToItem`）。
- 无歌词 → 居中显示「暂无歌词」+「从文件重新读取」文字按钮。

### P3 · 播放队列

从播放页底部上滑打开（也可点「队列」）。面板顶部圆角 28，高度 75%，内部可继续上拉到 95%。
- 标题行：「播放队列 · N 首」+ 「清空」文字按钮。
- 当前曲：左侧 3dp × 24 主色竖条 + 标题白色。
- 每行右侧拖拽手柄（`drag_handle` 图标），长按拖动排序，拖动中 `HapticFeedbackType.LongPress`。
- 左滑删除（`SwipeToDismiss`，阈值 40%，红色底）。

### S1 · 搜索

进入即聚焦，键盘自动弹出。顶部搜索框（48 高，全圆角，内含清除按钮）。
- 空查询：显示「最近播放」横向卡片（最多 8 个）+「最近添加」列表。
- 有查询：结果分三段——歌曲（最多 5 条 + 「查看全部」）/ 专辑（横滑卡片）/ 艺术家（横滑圆形）。段标题 12/500 大写。
- 防抖 300ms；本地结果先出，远程结果后到并**淡入追加**（不闪烁重排）。

### T1 · 设置

四个分组，`SettingRow` 高 64：标题 17/400 + 副标题 14/400 @variant + 右侧值/开关/箭头。

| 分组 | 项 |
|---|---|
| 音乐来源 | 本机目录（N 个）· OpenList 服务器（已连接/未配置）· 重新扫描 |
| 播放 | 仅 Wi-Fi 预加载（开关）· 均衡器 · 播放页默认显示歌词（开关） |
| 存储 | 封面缓存（12.4 MB）· 音频缓存（0 B）· 清理缓存（danger） |
| 关于 | 版本 · 开源许可 · 日志 |

### T3 · OpenList 服务器（配置页）

表单：地址 / 用户名 / 密码 / 测试连接。地址输入**实时规范化**（补 `https://`、去尾斜杠、剥离误粘的页面名），规范化后在下方灰字显示最终地址。
`http://` 输入 → 行内黄色警告条 + 二次确认对话框。
测试连接：按钮转圈，成功绿色条「连接成功 · 1234 首」，失败红色条 + 中文原因（DNS 解析失败 / 证书无效 / 账号或密码错误 / 连接超时）。

### E1 · 首次启动 / 空库

一页式（非轮播）：图标 + 「把本机的音乐，和你的云端曲库放在一起」+ 三条说明（只读不修改 / 不上传 / 可随时移除）+ 主按钮「授予权限」+ 次按钮「先看看」。
已授权但库为空：空状态插画（简单几何图形，非位图）+ 「没找到音乐」+ 「添加目录」+「配置 OpenList」。

## 5. 交互规格

### 5.1 手势总表

| 位置 | 手势 | 行为 | 冲突处理 |
|---|---|---|---|
| 迷你播放条 | 上滑 | 展开播放页（跟手） | 与列表滚动不冲突（条在列表外） |
| 迷你播放条 | 点击 | 展开播放页 | — |
| 迷你播放条 | 左右滑 | 切歌 | 阈值 30% 宽度 |
| 播放页 | 下滑 | 收起 | 边缘 24dp 内不响应（留给系统返回） |
| 播放页 | 左右滑 | 切歌 | 同上 |
| 播放页 | 上滑（底部） | 打开队列 | 仅从底部 72dp 区域内起手 |
| 列表行 | 长按 | 上下文菜单 | 500ms 触发 + 触觉反馈 |
| 队列行 | 长按拖动 | 排序 | 手柄区域优先 |
| 队列行 | 左滑 | 删除 | 阈值 40% |
| 歌词 | 点击行 | seek | — |
| 搜索框 | 点击 | 聚焦 + 弹键盘 | — |

### 5.2 动效

| 场景 | 曲线 | 时长 |
|---|---|---|
| 迷你条 → 播放页 | `spring(dampingRatio = 0.9, stiffness = 380)` | ~320ms |
| 封面共享元素 | 同上 | 320ms |
| 播放页 → 歌词 | `FastOutSlowInEasing` | 300ms |
| Tab 切换内容 | 淡入 + 4dp 上移 | 180ms |
| 列表项点击 | 涟漪（M3 默认） | — |
| 队列面板 | `spring(0.85, 400)` | ~300ms |

**系统「移除动画」开启时，全部降级为淡入淡出 120ms。**

### 5.3 反馈

- 点击播放键：图标 morph（播放 ↔ 暂停，150ms）+ `HapticFeedbackType.TextHandleMove`（轻）。
- 切歌：`HapticFeedbackType.LongPress`（中）。
- 拖拽排序：每跨过一行一次轻震动。
- **不做** Toast 提示「已加入队列」，改为队列图标上冒一个数字角标 1.5s。

## 6. 边界状态

| 状态 | 表现 |
|---|---|
| 扫描中 | 顶部 2dp 不确定进度条 + 列表实时追加，**不阻塞浏览、不弹窗** |
| 扫描完成 | 进度条消失；若新增 > 0，列表顶部插入一条 24 高提示「新增 12 首」，4s 后淡出 |
| 库为空 | E1 空状态 |
| 无权限 | 整页引导（保留现有 `AudioPermissionGate` 结构） |
| OpenList 未配置 | 「云端」芯片置灰，点击跳 T3 |
| 连接失败 | 红色条 + 具体原因，可关闭 |
| 断网播远程 | 暂停 + 顶部条「网络不可用」，恢复后**不自动续播** |
| 缓存满 | 静默 LRU 淘汰，不提示 |
| 曲目被删除（播放中） | 跳到下一首，列表行淡出移除 |
| 加载中 | 骨架屏（灰色圆角块 + 1.2s 呼吸），不用转圈 |

## 7. 自适应

真机是 **1280×720 横屏**，这一节不是可选项。

| 断点 | 布局 |
|---|---|
| < 600dp | 底部 `NavigationBar` + 单栏（手机竖屏） |
| 600–839dp | 左侧 `NavigationRail`（88dp，图标+文字）+ 单栏；迷你播放条变为底部横条（高 64） |
| ≥ 840dp | `NavigationRail` + **双栏**：左列表（固定 380dp）/ 右详情（自适应，最小 420dp）；播放页在右栏内展开为面板，不覆盖左栏 |

横屏额外规则：
- 列表行高不变，但一屏可见 8–10 行，边距增至 24。
- 播放页封面限制 `maxHeight = 屏高 × 0.62`，避免横屏封面撑爆。
- 队列面板在横屏变为右侧抽屉（宽 360dp），不是底部上滑。

## 8. 无障碍

| 项 | 要求 |
|---|---|
| 对比度 | 正文 ≥ 4.5:1，大字号 ≥ 3:1（`onStageSecondary` 66% 白在 `#0A0B0E` 上为 8.9:1，达标） |
| 触摸目标 | ≥ 48×48（视觉可 44，热区补足） |
| 字体缩放 | 200% 不截断：列表标题最多 2 行，副标题 1 行省略；播放页歌名最多 2 行 |
| TalkBack | 列表项朗读「歌名，艺术家，3 分 42 秒，正在播放」；播放键朗读「暂停」/「播放」而非「按钮」 |
| 焦点顺序 | 自上而下、自左而右；播放页为「收起 → 封面 → 歌名 → 进度 → 控制 → 入口」 |
| 减少动画 | 跟随系统开关 |

### 9.3 三个技术风险点

| 风险 | 应对 |
|---|---|
| 共享元素转场（迷你条封面 → 播放页封面） | Compose 1.7+ 的 `SharedTransitionLayout`；**若不稳定，降级为「封面淡入 + 轻微 scale 0.92→1」**，视觉损失可接受 |

## 11. 与 06 的差异汇总
