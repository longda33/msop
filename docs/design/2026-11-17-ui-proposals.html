定稿方案 A · 极光呼吸

极光呼吸

深空墨底上两团极光缓慢漂移，中央是应用图标本身，固定 92dp 不做缩放；图标里三根竖线错峰跳动，像一段没有声音的波形。

  • 1LOGO 换成应用图标：按 msop_icon.png 的实际几何重画成矢量——黄橙渐变圆 + 粉蓝渐变的耳机 + 三根均衡器竖条。矢量版放大不糊，也能单独动某一根柱子。
  • 2三根竖线都跳动：三根都以底边为轴做 scaleY，收缩幅度 0.30 / 0.40 / 0.34 各不同，延迟 0 / .19s / .38s 依次错开，读起来是一段波形，而不是三根一起抽搐。
  • 3去掉旋转外圈：原来那圈 9s 转一圈的暖金光环整圈删除，画面只剩极光和跳动的竖线，更安静、也不和图标本身的圆边抢戏。
  • 4图标固定尺寸：整枚图标不做呼吸缩放，稳定停在 92dp，不会有「忽大忽小」的廉价感。
  • 5副标题「私人唱片架」→「私人音乐库」，字距 .26em，与主标题的 .4em 拉开层级。
  • 6保留底部细进度条与「正在载入曲库」，冷启动慢时不显空。

定稿方案 B · 锚定气泡

锚定气泡

从右上角沙漏按钮正下方弹出，小三角指回触发点；三行列表，右侧显示条数，选中行左侧一道紫竖条。

  • 1空间关系清楚：谁点出来的、点的是什么，一眼看得见，比整屏 sheet 更轻。
  • 2加了一层 50% 蒙层：气泡是浮层，不加蒙层直接压住标签栏会像布局错位；点蒙层任意处即关闭。
  • 3选中态三处冗余：紫底 + 左侧 2.5dp 竖条 + 数字变紫，保证深色和浅色下都看得出当前是哪一档。
  • 4条数前置：选之前就知道会剩多少首，避免选完才发现是空的。
