视觉语言全部取自 msop 实际界面；导航、列表、详情页、播放页的信息组织方式取自 NeriPlayer 与 MusicFree 这两个国内用户量最大的开源安卓音乐 App。每屏标注了出处，没有一处是拍脑袋。

msop 视觉

深色底 #0A0A0C、蓝色强调 #3D5AF1、胶囊选中态、细进度条、圆角封面、底部胶囊播放条。播放页大封面 + 灰阶文字层级，全部照搬。

NeriPlayer 结构

手机 底部 Tab + 常驻迷你播放条；平板 ≥840dp 左导航栏 + 双栏；播放页左封面右歌词；音质标签 FLAC · 44.1 kHz。

MusicFree 习惯

顶部搜索框、歌单页「封面 + 共 N 首 + 播放全部」、列表行「序号 + 标题 + 副标题 + 时长 + 三点」、播放页功能行、歌词居中滚动。

手机 · 8 屏

412 × 915dp 基准，360–412dp 均适配

平板横屏 · 2 屏

真机 1280 × 720 的实际形态
为什么是深色：msop 全平台（iOS / macOS / tvOS）都是深色为主，播放页恒定深色。这里不做「浅色浏览 + 深色播放」的双主题，直接一套深色，减少一套配色的维护成本，也更接近原版。
为什么是 3 Tab：NeriPlayer 是「首页 / 探索 / 媒体库 / 设置」4 Tab，其中首页与探索服务于在线平台推荐。本项目只有本地 + OpenList 两种音源，没有推荐流，去掉这两个后剩下 音乐库 / 搜索 / 设置。
平板断点：最短边 ≥600dp 判平板；宽度 ≥840dp 切左侧导航栏 + 双栏，与 NeriPlayer 的规则一致。
